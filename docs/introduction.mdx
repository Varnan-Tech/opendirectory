## What is OpenDirectory?

OpenDirectory is an open-source registry of AI agent skills built for founders, growth engineers, and technical marketers. Each skill packages a verified workflow (`SKILL.md`), executable scripts (`scripts/`), and reference playbooks (`references/`) that install directly into your AI coding agent.

Instead of rewriting long prompts every session, install a skill once and your agent immediately knows what scripts to run, how to process data, and how to verify the output.

## Quick Start

<Steps>
  <Step title="Browse skills interactively">
    Launch the full-screen terminal UI to browse by category, search, and multi-select skills:
    ```bash
    npx "@opendirectory.dev/skills"
    ```
  </Step>
  <Step title="Pick your coding agent">
    Choose your target agent (`claude`, `opencode`, `codex`, `gemini`, `anti-gravity`, `openclaw`, or `hermes`):
    ```bash
    npx "@opendirectory.dev/skills" install show-hn-writer --target claude
    ```
  </Step>
  <Step title="Invoke the skill inside your agent">
    Ask your agent in plain English or trigger the skill directly with `/show-hn-writer`.
  </Step>
</Steps>

## Supported Coding Agents

| Agent | CLI Target Flag | Default Install Path |
|---|---|---|
| **Claude Code** | `--target claude` | `~/.claude/skills/` |
| **OpenCode** | `--target opencode` | `~/.config/opencode/skills/` |
| **OpenAI Codex CLI** | `--target codex` | `~/.codex/skills/` |
| **Gemini CLI** | `--target gemini` | `~/.gemini/skills/` |
| **Gemini Anti-Gravity** | `--target anti-gravity` | `~/.gemini/antigravity/skills/` |
| **OpenClaw** | `--target openclaw` | `~/.openclaw/skills/` |
| **Hermes** | `--target hermes` | `~/.hermes/skills/` |
| **Manus AI** | 1-click web import | Imported directly via [opendirectory.dev](https://www.opendirectory.dev) |

opendirectory supports five installation methods so you can equip any terminal or desktop AI agent in under 30 seconds.

<Tabs>
  <Tab title="npx CLI (Recommended)">
    Run the official `@opendirectory.dev/skills` CLI with zero global setup:

    ```bash
    # Launch interactive TUI browser
    npx "@opendirectory.dev/skills"

    # Or install a specific skill directly
    npx "@opendirectory.dev/skills" install <skill-name> --target claude
    ```

    <Note>
      Requires Node.js 22+. Pass `--target <agent>` explicitly, or run `install <skill-name>` in an interactive terminal without `--target` to pick a target and optionally save it as your default.
    </Note>
  </Tab>

  <Tab title="skills.sh">
    Install the entire opendirectory catalog or a single skill via [skills.sh](https://www.skills.sh/Varnan-Tech/opendirectory):

    ```bash
    # Install all skills (auto-detects your installed coding agents)
    npx skills add Varnan-Tech/opendirectory

    # Install a single skill
    npx skills add Varnan-Tech/opendirectory --skill <skill-name>
    ```

    Add `--global` to install to `~/.claude/skills/` instead of the current project directory.
  </Tab>

  <Tab title="Claude Code Native">
    Add the official opendirectory plugin marketplace directly inside Claude Code:

    ```bash
    # 1. Register the opendirectory marketplace
    /plugin marketplace add Varnan-Tech/opendirectory

    # 2. Install the skill pack
    /plugin install opendirectory-gtm-skills@opendirectory-marketplace
    ```
  </Tab>

    1. Copy the GitHub URL of the skill folder you want to install (for example, `https://github.com/Varnan-Tech/opendirectory/tree/main/skills/show-hn-writer`).

    3. Open the **Claude Desktop App**, click **Customize** in the left sidebar, open the **Skills** tab, and click **+**.
    4. Select **Upload a skill** and drag in the downloaded `.zip` archive or extracted folder containing `SKILL.md`.

    3. Click **Install in Manus AI** to open Manus with the GitHub skill URL pre-filled.
    4. Confirm the import inside your Manus workspace.

## Managing Installed Skills

Once installed via the CLI, you can inspect, update, or remove skills at any time:

```bash
# View installed skills across all agents
npx "@opendirectory.dev/skills" installed

# Update a skill with automatic rollback on failure
npx "@opendirectory.dev/skills" update <skill-name> --target claude

# Uninstall a skill
npx "@opendirectory.dev/skills" uninstall <skill-name> --target claude
```
